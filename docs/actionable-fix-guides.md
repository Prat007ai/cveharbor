# Actionable fix-guide release

The guide now retrieves a bounded public CNA record and, for supported .NET references, the Microsoft repository advisory. It selects explicit Windows runtime patch versions for the installed major/minor branch, retaining package identity. SDK versions are not substituted with runtime patch versions. Desktop Runtime includes .NET Runtime; a dependency vulnerability is not by itself conflicting product evidence.

Generation remains explicit. Public requests send only public CVE/GHSA identifiers, omit credentials and referrers, reject redirects, time out after six seconds per request, and stop at 512 KiB. A five-minute, 30-record memory cache contains public records only. Failed, mismatched, withdrawn or unpublished evidence cannot supply a patch. Existing accounting, allowance, model and retry identity remain unchanged.

The prompt requests numbered verification, vendor fix, deployment/restart and post-fix checks within the existing 6,000-byte input / 300-word answer limits. Missing vendor evidence produces conditional verification guidance. Safe DOM rendering handles headings, lists, emphasis, commands and numbered source links without interpreting HTML or arbitrary Markdown links.

The report score is labelled Provisional Inventory Review. Version/check completeness is distinguished from vulnerability coverage or verified exposure; the underlying score and saved history are unchanged.

## Validation

- Matching and guide unit tests: 36 cases, including branch selection, SDK separation, source identity, unsafe URLs, withdrawn records, oversized bodies, network failure and multibyte admission bounds.
- Desktop (1440px) and phone (390px) mocked browser flows: personal, organization and workspace entry points; no automatic paid requests; duplicate-click protection; stable retry evidence/key; literal HTML; numbered actions/citations; report filtering/printing and provisional score wording.
- Real vendor content and production verification recorded on the PR after release. Fictional tests do not establish generated answer quality by themselves.

## Limits

This is guidance, not endpoint scanning or patch installation. Generic products use published CNA solutions/workarounds when available plus indexed evidence. Detailed repository evidence retrieval currently covers reviewed Microsoft .NET repositories only. Missing or incomplete advisory content, installed patch details, app architecture and deployment mode still require customer verification. Source enrichment does not change finding applicability or saved remediation status. Upstream failures degrade to verification guidance; customer navigation never waits for an AI response.
